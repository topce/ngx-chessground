_normalizeTimeControl(tc: string)

Converts a human-readable time control format to a normalized one.

Supports:

  • "M+SS" with optional + (e.g. "5+0", "3:0")
  • "M+SS" format with minutes and seconds (e.g. "5+30" = 5 min + 30 sec)
  • "seconds+increment" already normalized (e.g. "300+0")

extractMovesFast
extractMovesFast(pgn: string)

Extracts SAN moves from a PGN string without using a full chess engine parser.

Used for filtering by opening moves — faster than full chess.js parsing. Steps:

  1. Isolates move text after header tags, handling bracket comments like [%clk ...].
  2. Strips { ... } and ( ... ) comments and ; ... line comments.
  3. Removes move numbers, result markers, and NAG symbols ($1, $2).
  4. Splits by whitespace, strips !/? annotations, and validates SAN format.
Parameters :
Name Type Optional Description
pgn string No

— Raw PGN string for a single game (header tags + move text).
Returns : string[]

Array of clean, validated SAN move strings.

handleLoad
handleLoad(pgn: string, id: number, indexStartPositions: boolean, maxFenPlies: number, pgnHash?: string, useDiskCache: unknown)

Loads raw PGN text: splits into individual games, filters out non-Standard variants, extracts metadata, builds FEN position cache, and posts a 'load' response with game count and metadata. Progress updates are posted during the process.

When pgnHash is provided and a cache entry exists (IndexedDB in the browser, a file on disk in the desktop app), the entire parsing and FEN-indexing step is skipped — the worker state is restored from the cache.

isUpsetGame
isUpsetGame(info: GameMetadata, upsetWin: boolean, upsetDraw: boolean, minEloDiff: number)

Determines whether a game counts as an upset against the rating gap.

An upset requires:

  • both players to have a known (non-zero) Elo rating,
  • the rating gap to be at least minEloDiff,
  • the weaker player (lower Elo) to either win the game (upsetWin) or hold a draw (upsetDraw), per the enabled outcome flags.
Parameters :
Name Type Optional Description
info GameMetadata No

— Metadata for the game being tested.
upsetWin boolean No

— Whether a weaker-player win counts as an upset.
upsetDraw boolean No

— Whether a weaker-player draw counts as an upset.
minEloDiff number No

— Minimum absolute Elo gap required.
Returns : boolean

true if the game is an upset under the given settings.
